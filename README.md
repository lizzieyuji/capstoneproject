# Numerical Eigenstates of the 1D Quantum Harmonic Oscillator

This is Team 7's final-project repository. The primary deliverable is
qho_project.py, a single runnable program that constructs the finite-difference
Hamiltonian, calculates the six lowest eigenstates, validates the physics, runs
independent grid-spacing and box-size studies, and writes the final tables and
figures.

## Quick start

From the repository root:

    python -m pip install -r requirements.txt
    python qho_project.py
    python -m unittest discover -s tests -v

The complete default run takes only a few seconds on a typical laptop. Results
are written under results/, and the four automated tests should all pass.

For a different output location:

    python qho_project.py --output-dir my_results

For the baseline configuration options:

    python qho_project.py --help

## Shared numerical conventions

| Quantity | Baseline choice |
| --- | --- |
| Units | Dimensionless: hbar = m = omega = 1 |
| Full interval | x in [-8, 8] |
| Full grid points | N = 1000, including endpoints |
| Interior unknowns | M = N - 2 = 998 |
| Boundary condition | Dirichlet: psi(-8) = psi(8) = 0 |
| Derivative | Centered, second-order finite difference |
| Matrix | Real symmetric tridiagonal sparse matrix |
| Requested states | Lowest six, n = 0 through 5 |
| Eigensolver | Sparse shift-invert eigsh, checked independently |
| Spatial normalization | dx times sum of abs(psi)^2 equals 1 |

## Verified results

The current generated results show:

- a largest baseline absolute energy error of 4.89e-4, or 0.0089 percent;
- agreement between eigsh and eigh_tridiagonal within 3.93e-13;
- normalization and orthogonality errors below 5e-16;
- the correct parity and number of nodes for every requested state;
- grid-convergence orders from 2.0001 to 2.0005, as expected for the
  centered second difference;
- a largest L=7 to L=8 energy change of 2.19e-13 at fixed dx = 0.02; and
- a largest near-boundary amplitude of 4.37e-11 at L = 8.

These values are regenerated by the code and stored in results/summary.json.

## Generated artifacts

Running the program creates:

- energy_comparison.csv;
- state_validation.csv;
- grid_convergence.csv and grid_convergence_orders.csv;
- box_convergence.csv;
- summary.json; and
- six report-ready figures under results/figures/.

The timing values are machine-dependent and may change slightly between runs.
The energies, convergence orders, and validation tolerances are deterministic.
